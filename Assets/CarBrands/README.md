# Car brand marks

These local thumbnails were sourced from the MIT-licensed
[`car-logos-dataset`](https://github.com/filippofilip95/car-logos-dataset)
(snapshot retrieved 2026-08-15). The marks remain trademarks of their
respective owners and are used only to identify a selected vehicle brand.

`maruti-suzuki.png` uses the Suzuki marque from that dataset because the
Indian consumer taxonomy names the manufacturer as Maruti Suzuki.
