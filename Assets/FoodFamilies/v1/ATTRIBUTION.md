# Food image attribution

Each final image is a 4:3 crop of the linked real photograph. Keep this file with the asset pack.

The manifest records a logical media path for every file:
`food → collection → family`. Runtime classification may understand an
additional fourth-level variant (for example `chicken_fried`), while this v1
pack deliberately falls back to the family image at depth 3.
